> **Note:** This repository is a fork of the original Edda project by PKBeam, rewritten to Avalonia for better Linux support.
> For actively maintained fork of the original Edda editor, check out https://github.com/watsu78/Edda.

Edda is an editor that lets you map custom songs to levels for the VR rhythm game [Ragnarock](https://www.ragnarock-vr.com/home).

User documentation (such as installation and usage instructions) can be found at https://brollyy.github.io/Edda/.

If you are interested in contributing to the source code, partial developer documentation can be found [here](https://github.com/Brollyy/Edda/wiki).
